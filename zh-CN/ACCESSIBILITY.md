# 无障碍声明

我们希望残障人士也能顺畅地使用并为大象-金鱼模型（EGM）做出贡献。欢迎提交无障碍问题报告与改进贡献。

## 范围与目标

本声明涵盖本仓库的文档、共享技能内容以及 [EGM 官网](https://egm.dev)。

我们针对官网设定的目标是遵循 Web 内容无障碍指南 [WCAG 2.2 Level AA](https://www.w3.org/TR/WCAG22/)。这是一项努力目标，而非已通过认证的合规声明。

优先关注点包括：键盘访问、可见焦点、易读文本、充足对比度、清晰的标题与链接、文本替代方案以及减弱动态效果（reduced motion）。对于文档与生成的报告，优先使用平实清晰的语言和文本，不单纯依赖颜色或图表来传达信息。

## 运行环境与当前限制

EGM 提供的是 Markdown 技能与文档，其交互体验运行在 AI 编程智能体或宿主应用内部。关于安装与验证边界，请参阅[宿主环境指南](docs/harnesses.md)。支持某一宿主环境并不等同于确立了无障碍支持。

官网包含跳转至主内容的链接（skip link）、键盘焦点样式以及减弱动态效果样式。这些特性并不代表每个页面都完全无障碍。本声明不对任何浏览器、屏幕阅读器、终端或宿主应用的组合做出认证。针对本声明，我们尚未建立全面的无障碍审计与辅助技术测试矩阵。

已知限制包括：

- 宿主应用自行控制其聊天、终端与插件界面。EGM 无法修复这些界面中的所有无障碍障碍。
- 模型生成的文档可能包含表述不清的文本、复杂表格或缺乏充分文字说明的图表。依然需要人工审阅。
- 自动化单元测试与构建检查无法证明键盘可用性、屏幕阅读器支持或 WCAG 合规性。

当渲染后的视图不便使用时，可以直接以 Markdown 形式阅读源文档。你也可以要求你的 AI 编程智能体输出纯文本报告，或为图表提供文字解释。这些替代方式或许有帮助，但不能替代对底层障碍的修复。

## 报告无障碍障碍

请使用[缺陷报告模板](https://github.com/google/elephant-goldfish-model/issues/new?template=bug_report.md)，并将报告标明为无障碍问题。请尽可能提供以下信息：

- 受影响的页面、文档、技能或任务。
- 你的预期行为，以及阻碍你完成任务的具体现象。
- 复现步骤，相关时请附上键盘操作步骤。
- 浏览器或宿主应用、操作系统以及辅助技术的版本号。
- 是否存在绕行方案，以及该障碍是否阻塞了核心任务。

截图和录屏为可选项。请勿包含凭证、私有项目内容或医疗信息。报告无需指明具体的 WCAG 条款，也不必附带修复建议。

## 贡献无障碍改进

请遵循[贡献指南](CONTRIBUTING.md)。描述具体障碍并记录你执行过的检查。针对官网的修改，请尽可能检查键盘导航、焦点可见性、缩放与重排，以及受影响的屏幕阅读器行为。对于未能执行的检查项请如实说明。请将自动化检查与手动测试结合使用，并为有意义的图片与图表提供文本替代方案。
