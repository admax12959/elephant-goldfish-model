# 共享技能图标

状态：已实现（Implemented）。权威图形资产由插件、README 与官网共享。
作者：@n3wth。日期：2026-10-25。

## 目的与范围

在插件选择器、README 与 egm.dev 中统一使用同一套七个技能标志。已批准的图形采用具有双色切面（two color facets）的熟悉剪影造型。本次变更仅替换现有的技能图形资产；不更改技能行为、评审员权限、安装方式或大象-金鱼主标志（logo）。

## 源文件与几何规范

每个 `skills/egm-*/assets/icon.svg` 均为权威资产（canonical asset）。保持 SVG 自包含，带有 `<title>` 且使用 24 × 24 的 `viewBox`。可见墨迹保持在 20 px 参考线（keyline）以内。视觉尺寸与定位微调属于图形设计的一部分；不要对单个边界框或描边宽度进行机械归一化。

| 技能 | 图形标志 | 底色 / 切面色 |
| --- | --- | --- |
| Bootstrap | 圆角加号：初始化项目文档 | `#1b6ef3` / `#7cacf8` |
| Brainstorm | 灯泡：探索构想 | `#1b6ef3` / `#7cacf8` |
| Draft | 铅笔：撰写设计文档 | `#1b6ef3` / `#7cacf8` |
| Lite | 火花：快速工程迭代 | `#1b6ef3` / `#e86e00` |
| Resolve | 勾选：处理评审发现项 | `#1b6ef3` / `#7cacf8` |
| Drift report | 相接但错位的两半：文档与代码产生漂移 | `#e86e00` / `#ff8d41` |
| Review | 放大镜：检视文档 | `#e86e00` / `#ff8d41` |
| Review loop | 循环箭头：重复多轮评审 | `#e86e00` / `#ff8d41` |

## 使用方

- Codex 元数据继续将两个图标字段均指向 `./assets/icon.svg`。其 `brand_color` 与图标底色保持一致。宿主渲染由宿主环境控制；元数据校验并不验证宿主选择器的 UI 呈现。
- 两个运行时产物包均通过现有的[打包构建器](../../../scripts/pack_plugin.py)包含这些权威文件。不要独立编辑生成的副本。Claude 的评审员颜色关键字以及插件级主标志保持不变。
- 仓库根目录 README 直接引用这些权威路径。这些相对路径在生成的运行时产物包内同样可以正确解析。
- 官网的 `site/src/components/SkillIcon.astro` 在构建时导入这些 SVG，并将其标记为紧邻文字标签的装饰性元素。

## 验证与发布

检查元数据颜色与 SVG 结构、运行时字节一致性以及 README 图片引用。官网集成会接受独立的构建检查与视觉检查。所有七个标志在紧邻各自标签时都必须保持清晰可辨。
