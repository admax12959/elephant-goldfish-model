# EGM 数据处理说明

EGM 是一套技能、评审员指令以及本地文档工作流的集合。其运行时包不运营任何托管服务、数据库、分析客户端或遥测端点，也不需要单独的 EGM 账号或凭据。

## 输入与输出

宿主助手会读取为所选任务提供的项目文件、设计文档、提示词以及评审上下文。这些输入可能包含个人或机密信息，请仅提供评审所必需的文件。

EGM 会将简报、设计文档、README 文件与评审报告写入用户的工作区或宿主的产物存储中。输出内容可能会复述输入中的信息。本地文件会一直保留直至用户主动删除；EGM 不会应用自动保留期限。

## 处理过程与外部服务

所选宿主会依据其自身的账号设置、服务条款和隐私政策，处理提示词、文件、模型响应及智能体活动。原生智能体调用使用用户的宿主账号。EGM 无法控制宿主的会话记录、产物、备份或模型提供商的数据保留策略。

引导初始化（Bootstrap）可能会运行本地发现命令以及项目中已配置的格式化工具。格式化工具或其他经用户批准的项目命令可能会连接包注册表或其他外部服务。请使用宿主的权限控制机制审查并授权这些命令。EGM 的运行时不声明任何 MCP 服务器，也不安装任何权限自动审批钩子（hook）。

## 开发工具

源码仓库中还包含可选启用的集成测试。在显式启用时，这些测试会调用宿主 CLI 并检查其自身测试会话生成的记录，以验证评审员隔离性。这些测试不包含在运行时发布包中；网站与开发工具同样被排除在外。

## 咨询与反馈

一般性问题请使用 [Issue 追踪器](https://github.com/google/elephant-goldfish-model/issues)。切勿在公开报告中包含凭据、私密文档或个人数据。本说明仅描述插件的数据流向，不能替代用户所调用的宿主或外部服务的隐私政策。
