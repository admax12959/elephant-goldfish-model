# 测试计划：金鱼评审循环技能（Goldfish Review Loop Skill）

Frontmatter 与链接检查在 `pytest tests/unit` 中运行（参见 [TESTING.md](../../TESTING.md)）。

## 协议验证清单

在聊天中交互式评估或探索 `egm-review-loop` 时，请验证以下各项：

-   **第 1 步（输入采集与配置）：** 校验必填输入、解析标准路径，并在第一轮前将 `GoldfishContext` 中的每个 URL 保存为文件，对无法保存的页面向用户索取本地副本。
-   **第 2.1 步（目标解析）：** 每次审计前无条件重新扫描行号。
-   **第 2.2 步（评审蜂群）：** 跨所请求的文档标准派生子智能体（或在降级模式下顺序遍历人格）。
-   **第 2.3 与 2.4 步（裁决交接与回合边界）：** 将发现交接给 `egm-resolve`，并严格尊重人类决策门禁。
-   **第 2.4 步（轮次控制，Round Control）：** 保持已提出异议和已接受风险的发现处于已裁决（`Settled`）状态，重新打开被评审员再次提出的已修复（`Fixed`）发现，在应用本轮修复前判定净轮次（`Clean Round`），将失败评审员（以及合成器汇总中缺少状态的评审员）记录为 `not run`，连续两个净轮次即判定已收敛（`Converged`）并停止，且在达到 5 轮上限（`Cap`）或出现修复振荡（`Churn`）时询问用户。
